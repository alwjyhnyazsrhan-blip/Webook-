# نماذج أتمتة الويب وإدارة الجلسات (Puppeteer Session Automation)

هذا المجلد يحتوي على نماذج برمجية بلغة Node.js باستخدام مكتبة Puppeteer لإدارة الجلسات واستخراج وحفظ ملفات الكوكيز (Cookies).

## الملفات المتاحة:
- `index.js`: السكربت التنفيذي الرئيسي لاختبار تسجيل الدخول واستخراج الكوكيز.
- `sessionManager.js`: وحدة تخزين واسترجاع الجلسات والكوكيز محلياً.

## متطلبات التشغيل:
1. بيئة Node.js 18 أو أحدث.
2. تثبيت مكتبة Puppeteer:
   ```bash
   npm install puppeteer
   ```

## التشغيل:
```bash
node index.js
```
